Как устроен этот сайт

Каждый git push в main проходит весь путь до продакшена без ручных действий.

  1. git push GitHub / GitLab
  2. CI валидация, сборка образов, дерево Miki
  3. SSH deploy .env из секретов → сервер
  4. upload архив проекта → /opt/petweb
  5. compose up health-check nginx
