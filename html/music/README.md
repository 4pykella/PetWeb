# Музыка для плеера на визитке

Положи сюда аудиофайлы — они появятся в скрытом плеере на главной странице
(открывается сочетанием **Ctrl + Alt + M** или если набрать на странице слово `music`).

- Форматы: `mp3`, `ogg`, `opus`, `m4a`, `aac`, `flac`, `wav`, `webm`.
- Название трека берётся из имени файла: `Исполнитель - Название.mp3`.
- Порядок — по алфавиту, удобно нумеровать: `01 - ...`, `02 - ...`.

Два способа добавить музыку:

1. **Через git** — закоммить файлы в `html/music/` и запушь, CI выложит их на сервер.
   Большие файлы раздувают репозиторий — для многих треков лучше способ 2.
2. **Сразу на сервер** — скопируй файлы в `/opt/petweb/html/music/`:
   ```bash
   scp *.mp3 root@SERVER:/opt/petweb/html/music/
   ```
   nginx сам отдаёт список файлов папки, перезапуск не нужен. Деплой их не удалит.

Локально (без nginx) плеер читает `playlist.json`: `node html/music/generatePlaylist.js`.
