# Zapret linux
[Ссылка на официальный Git](https://github.com/Sergeydigl3/zapret-discord-youtube-linux)

Применять только на один порт для эффективной работы. Хорошо работает с WG.

## Быстрый старт
```bash
git clone https://github.com/Sergeydigl3/zapret-discord-youtube-linux.git
cd zapret-discord-youtube-linux

./service.sh download-deps --default
./service.sh
```
