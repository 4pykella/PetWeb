# Инструкция по подключению 
## Что входит в доступы?
Два конфигурационных файла для wireguard и один для telegram. Конфигурационный файл для телефона приходит в виде QR кода, для компьютера в формате файла .conf. 

## Где скачать и что такое вайгвард ваш?
Wireguard - это открытый протоко шифрования. У технологии есть клиент (вы) и сервер (где-то где работет). Для клиентов сделаны удобные клиенты для популярных систем и представлены на [официальном сайте](https://www.wireguard.com/install/).
Скачать можно с сайта или с магазина приложений вашего устройства.

## Как подключить?
Скачиваем wireguard с официального сайта или с магазина приложений.

### Для телефона
1) Заходим в приложение.
2) Снизу справа нажимаем на +
3) Сканировать из QR-кода
4) Отсканируйте код и назовите как угодно
5) Нажмите на слайдер для включения

### Для компьютера
1) Ставим приложение
2) Слева снизу нажимаем добавить тунель
3) Выбираем из файла
4) В проводнике выбираем присланый файл.
5) Нажимаем активировать

### Телеграм
Может быть отправлен как ссылкой, так и QR-кодом. Ссылку открываем из баузера, если не запускается читаем ниже. QR-код может просто сканироваться.

Если не работает ссылка заходим в меню добавить прокси и разбираем ссылку на части.
Из ссылки мы вставляем в соотвествующие поля параметры:
https://t.me/proxy?server= адрес_сервера &port= порт &secret= длинный_код

Адрес сервера вставляем в поле хост, порт в порт, длинный код в поле ключ.
